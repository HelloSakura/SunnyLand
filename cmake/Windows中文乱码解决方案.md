# Windows BAT 脚本中文乱码解决方案

## 🔍 问题原因

Windows 批处理脚本（.bat）输出中文乱码的主要原因：

1. **代码页不匹配**：Windows 控制台默认使用 GBK/CP936 代码页，而文件可能是 UTF-8 编码
2. **文件编码问题**：脚本文件本身不是 UTF-8 编码
3. **控制台字体**：控制台字体不支持中文字符显示

## ✅ 解决方案

### 方法 1：设置 UTF-8 代码页（推荐）

在脚本开头添加：

```batch
@echo off
REM 设置代码页为 UTF-8
chcp 65001 >nul 2>&1

echo 正在清理构建目录...
```

**说明：**
- `chcp 65001`：将代码页设置为 UTF-8
- `>nul 2>&1`：隐藏 chcp 的输出信息，避免显示"Active code page: 65001"

### 方法 2：使用 GBK 编码（不推荐）

如果不想使用 UTF-8，可以：
1. 将文件保存为 GBK/ANSI 编码
2. 使用 `chcp 936` 设置代码页

**缺点：** 跨平台兼容性差，不推荐

### 方法 3：避免使用中文（最简单）

如果不需要中文输出，直接使用英文：

```batch
@echo off
echo Cleaning build directory...
echo Warning: This will delete all build files!
```

## 📝 当前实现

`cleanup.bat.in` 文件已经添加了 UTF-8 代码页设置：

```batch
@echo off
REM 设置代码页为 UTF-8 以支持中文显示
chcp 65001 >nul 2>&1

echo 正在清理构建目录: @CMAKE_BINARY_DIR@
echo 警告: 这将删除所有构建文件!
```

## 🔧 验证方法

1. **重新生成脚本**：
   ```bash
   cd build
   cmake ..
   ```

2. **运行脚本测试**：
   ```cmd
   build\cleanup.bat
   ```

3. **检查输出**：应该能看到正确的中文显示

## ⚠️ 注意事项

1. **文件编码**：确保 `.bat.in` 模板文件以 UTF-8 编码保存
2. **控制台字体**：某些旧版 Windows 控制台字体可能不支持 UTF-8，需要手动设置字体为"新宋体"或"Consolas"
3. **CMake 生成**：CMake 的 `configure_file` 会保持原文件的编码，所以模板文件必须是 UTF-8

## 💡 最佳实践

1. ✅ **统一使用 UTF-8**：所有文件（.bat, .cpp, .json）都使用 UTF-8 编码
2. ✅ **在脚本开头设置代码页**：确保输出正确显示
3. ✅ **隐藏 chcp 输出**：使用 `>nul 2>&1` 避免干扰
4. ✅ **测试验证**：在不同 Windows 版本上测试

## 🐛 常见问题

### Q: 设置了 chcp 65001 还是乱码？
A: 检查：
- 文件是否以 UTF-8 编码保存
- 控制台字体是否支持中文
- 是否在脚本开头就设置了代码页

### Q: 如何查看当前代码页？
A: 运行 `chcp` 命令（不带参数）

### Q: 如何永久设置代码页？
A: 在注册表中修改，但不推荐。建议在每个脚本中设置。
